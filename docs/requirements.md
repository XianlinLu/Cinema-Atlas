# Cinema Atlas 当前需求基线

本文件保留本对话已确认的约束，供后续维护对照。导入运行所需规则全部内置于 Skill，不依赖本文件或私人文档在线可访问。

## 使用与导入

- Lumina 画布 Agent 使用的 Skill；由用户给出一句话或想法，Agent 推理选题、风格与完整剧本。
- 单文件字符上限现为 **30,000**；按 UTF-16 保守计数，打包上限 **29,600**，保留余量。文件与目录计数仍按最多 50 项保守处理。
- 保留 `SKILL.md / agents / references` 结构；支持的文本格式与合法文件名；专用目录整包替换，避免旧文件叠加。
- 全部 **59 种风格全文**无损保留，风格名称与分类可索引；只按需加载选中风格全部片段。方法与媒介语言可以参考，示例故事、角色、构图和配乐不直接复用。
- 当前发布目标为 `XianlinLu/Cinema-Atlas` 的 main；README 保留中英文介绍。既有工具包与无关文件不被覆盖。

## 用户体验与审批

- 从想法先生成完整剧本，片长按剧本节奏与自然语速决定，不能强行限制成统一短时长。
- 所有需要用户判断、确认、自定义修改的节点使用实际 Lumina 原生 Question 卡片。卡片内可点选；修改说明在原生文本／Other 内填写，常规流程不要求在主聊天框多轮输入“继续”。
- 只在关键创意节点和真实不可恢复阻塞等待用户；确认返回后立即执行下一项已授权动作。
- 忽略、超时、预选推荐和生成成功均不等于用户批准。审批绑定真实产物与版本；所有分镜当前版本逐一确认。
- 原生工具、卡片与编辑器调用必须使用当前实际暴露的名称、参数和素材连接；不打印模拟调用，不虚构 API，不替换成外部编辑器。

## 完整生产顺序

1. 完整剧本、风格、节奏与预计时长 → 原生剧本确认。
2. 每个需明确身份的出镜剧情角色（包括只出现一次的发声角色）16:9 正／侧／背同身份三视图 → 原生角色确认。
3. 每个发声角色与独立旁白的声音要求点选 → 实际约 20–30 秒干声试音 → 原生试听确认。无声角色不造假音频，旁白不造假人物图。
4. 已批准剧本、角色、声音形成镜头生产总表；逐字台词、真实音频引用、实测时长、分镜、时间轴与依赖可追溯 → 原生总表确认。
5. 自动生成全部分镜并技术检查；默认 Seedance 2.5、16:9，仅用户明确指定比例才覆盖。每段模型背景音乐在用户确认前原生去除，保留或恢复正确对白／旁白并检查口型。
6. 同 scene 且时间、动作、角色、服装、光线、机位连续，前段 QC 就绪且比例一致时，可使用真实视频续写；不同 scene、时间跳跃、动作不连续则独立生成。续写继承源比例并裁去重复前缀。视觉转场硬切。
7. 用户逐段确认所有实际分镜当前版本 → 原生后期方式：仅拼接／仅字幕／两者／Other。
8. 选两者后自动使用 Lumina 原生 Video Editor 完成拼接与字幕；有已规划配乐时以独立轨道添加，并按真实节拍／乐句安排剪点，保留完整对白、动作和停顿。
9. 实际预览 → 原生成片确认或继续修改。修改时在卡片内说明哪段／哪个时间点、哪个点、怎么改；同一编辑器项目局部修改，重新预览并确认，直到明确批准。
10. 导出已批准当前版本，确认真实媒体可播放且可下载，再返回最终剪辑视频。云草稿、任务提交、第一段视频或散落素材不冒充整片。

## 可靠性与恢复

- 真实角色—声音—台词—音频映射；试音母版、短声音参考与实际台词音频分开管理。
- 提交前检查素材 ID 类型、内容非空、上传注册就绪、权限／版本／归属；不得向普通 TTS 强行传角色图片或未来音频。默认角色试音逐个自动排队，保留独立成功结果。
- `content id is empty` 与参数、临时失败、版权／内容拦截分别处理；有实际技术修复才有限重试，同一任务重复通知不重复生成。未知内部原因不能编造。
- 当前模型音频单条、数量、合计时长和续写画幅按真实运行约束检查。不能用整段多人试音塞满单次视频请求。
- 平台内容拦截停止盲目重试；真实原创素材修改需原生确认，或平台复核。不能通过变声、隐藏名称、换接口、提取被拦结果来规避。
- 保存阶段、批准版本、真实素材与任务、原始／去配乐分镜、续写依赖、原生编辑器草稿与版本、字幕、配乐节拍、最终导出及下一动作。中断后先对账再继续，避免重复付费提交。
- 技术 QC 与用户批准区分；总表已批准时，同场景后续段可消费 QC_READY 前段，无需提前等待稍后的逐段用户确认。后期前仍需全部当前分镜批准。
- 批准的生产表与后期编辑映射分别版本化；只重做受影响依赖，保留正确角色、声音、分镜和人工作业。字幕根据实际剪辑时间轴更新。
- 必须依赖真实原生工具与后台续跑能力；Skill 文本不能安装缺失功能、保证平台审核或自行唤醒。验证不到的能力或结果如实标注，不虚报全自动实测完成。
