# Style direction

Choose a style because it helps the story communicate. Do not give the user a long style menu unless they ask to browse options.

## Match style to intent

Consider the subject's texture and scale, the emotional tone, the pace of the story, and the amount of information each scene must carry. Choose one primary visual language and describe it through observable decisions:

- **Palette:** a restrained set of colors and the role of an accent.
- **Forms:** geometric, organic, diagrammatic, hand-drawn, layered, or another fitting shape vocabulary.
- **Surface:** clean vector, paper grain, ink, soft wash, halftone, or another supported treatment.
- **Light and depth:** flat graphic, atmospheric, dimensional, or intentionally minimal.
- **Type:** short labels with a clear hierarchy and readable contrast.
- **Motif:** a recurring object, line, shape, or color that changes meaning across scenes.

Use a style contrast when it clarifies the idea, such as warm subject against a cool environment. Avoid stacking unrelated aesthetics, decorative effects that hurt legibility, and unsupported claims about generated media.

## Make the choice legible

Give a one-sentence rationale linking style to story, for example: “A quiet ink-and-paper look gives the memory a handmade, intimate quality.” Then apply the same rules consistently across scenes. If the user named a style, honor it and refine its visual treatment rather than silently substituting another.

## Adapt to available tools

Use only visual properties the active canvas tools can express. If a requested texture, image, or effect is unavailable, approximate it with supported native elements or explain the limitation briefly. Never present a textual style description as if it had already been rendered.
