# Canvas composition

Use this guide when turning the selected story and style into a readable canvas.

## Scene card

Plan each scene with a compact internal note:

1. Scene number and short title.
2. One visible action or change.
3. Main subject and focal point.
4. Camera or framing cue when it helps.
5. One short caption or narration line only when useful.
6. Transition or motif carried into the next scene.

The note guides drawing; it does not need to become a block of text on the finished canvas.

## Arrange for reading

- Choose a layout that fits the canvas and number of scenes. Use a consistent left-to-right, top-to-bottom order unless another direction is intentional and clearly signaled.
- Separate scenes with whitespace, borders, or subtle background shifts. Keep gutters, title placement, labels, and caption hierarchy consistent.
- Give each scene one dominant focal point. Use scale, position, contrast, and directional cues to guide attention.
- Keep on-canvas words short and readable at normal viewing zoom. Put detail in a concise note only when the user needs it.
- Reuse a small number of visual motifs so transitions feel connected without making every panel identical.
- End with a deliberate final frame: resolution, reveal, emotional echo, or clear next step.

## Editing an existing canvas

Inspect before editing whenever the tools permit. Preserve unrelated work and match existing conventions if the user is extending a canvas. If the available tools cannot reveal the current canvas and the requested change could overwrite it, ask before destructive edits.

## Delegation brief

When another agent performs the drawing, hand off one complete instruction containing the premise, scene order, style rules, layout, exact visible text, constraints, and inspection criteria. Do not rely on hidden conversational context.
